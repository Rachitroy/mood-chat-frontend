## 🎯 Common Tasks

### Change Primary Color
1. Open `src/styles.css`
2. Find `:root` section
3. Update `--mood-flirty: #ff6b9d;`
4. Changes apply everywhere automatically

### Adjust Animation Speed
1. Open `src/styles.css`
2. Find animation definitions
3. Change `400ms` to desired duration
4. Affects all matching animations

### Modify Spacing
1. Open `src/styles.css`
2. Update padding/margin values
3. Or adjust `--radius` variable
4. Changes propagate throughout

### Add New Theme
1. Use design tokens from `:root`
2. Create new color variants
3. Update component styles
4. Reference design system
